## General

Folosiți majusculă doar la prima literă a primei cuvinte dintr-o propoziție în documentație sau elemente de interfață, cu excepția numelor proprii și a acronimelor.

| Corect ✅ | Incorect ❌ |
| :---- | :---- |
| <ul><li>Creare cont</li><li>Testare experiență nouă</li><li>Activare seller</li><li>Dezactivare seller</li></ul> | <ul><li>Creare Cont</li><li>Testare Experiență Nouă</li><li>Activare Seller</li><li>Dezactivare Seller</li></ul> |

### Nume proprii

Folosiți majuscule pentru toate substantivele proprii și mărcile înregistrate, inclusiv numele de **produse**, **funcționalități**, **module**, **pagini**, **persoane**, **locuri** și **sărbători**. În numele compuse, folosiți majuscule doar la cuvintele cărora li se aplică regula.

| Corect ✅ | Incorect ❌ |
| :---- | :---- |
| <ul><li>Black Friday va avea loc pe 24 noiembrie.</li><li>Intelligent Search determină relevanța fiecărui produs prin combinarea ponderilor.</li><li>Contactați echipa de Suport.</li><li>Export în Excel</li><li>Instalare Intelligent Search</li><li>VTEX App Store</li></ul> | <ul><li>black friday va avea loc pe 24 noiembrie.</li><li>Intelligent search determină relevanța fiecărui produs prin combinarea ponderilor.</li><li>Contactați echipa de suport.</li><li>Export to excel</li><li>Instalare intelligent search</li><li>VTEX app store</li></ul> |

Păstrați capitalizarea originală a numelor companiilor așa cum apar în materialele lor instituționale (cu excepția logotipului). Aceasta include utilizări cu toate literele majuscule, o literă majusculă la mijloc sau toate literele minuscule.

| Corect ✅ | Incorect ❌ |
| :---- | :---- |
| <ul><li>VTEX</li><li>SAP</li><li>ServiceNow</li></ul> | <ul><li>Vtex</li><li>Sap</li><li>Servicenow</li></ul> |

### Zile ale săptămânii, luni, naționalități și limbi

În română, zilele săptămânii, lunile și adjectivele de naționalitate **nu se scriu cu majuscule**, cu excepția cazului în care se află la începutul propoziției.

| Corect ✅ | Incorect ❌ |
| :---- | :---- |
| <ul><li>De luni până vineri</li><li>Sâmbătă</li><li>Factură din noiembrie</li><li>Promoție valabilă până în februarie</li><li>Campanie destinată publicului columbian</li><li>Produs brazilian</li><li>Text scris în engleză</li></ul> | <ul><li>De Luni până Vineri</li><li>sâmbătă</li><li>Factură din Noiembrie</li><li>Promoție valabilă până în Februarie</li><li>Campanie destinată publicului Columbian</li><li>Produs Brazilian</li><li>Text scris în Engleză</li></ul> |

### Majuscule după bară (/)

Dacă cuvântul dinaintea barei începe cu majusculă, cuvântul de după bară trebuie de asemenea să înceapă cu majusculă.

| Corect ✅ | Incorect ❌ |
| :---- | :---- |
| <ul><li>Articole/Unități</li><li>Observație/Cod vânzător</li><li>Autentificare/Înregistrare utilizator</li></ul> | <ul><li>Articole/unități</li><li>Observație/cod vânzător</li><li>Autentificare/înregistrare utilizator</li></ul> |

### Formate de fișiere

Folosiți majuscule pentru numele formatelor și programelor care sunt mărci înregistrate sau nume proprii, cum ar fi Excel, Word, PowerPoint și PDF. În plus, când numele fișierului este scris cu majuscule, **nu** trebuie urmat de punct.

| Corect ✅ | Incorect ❌ |
| :---- | :---- |
| <ul><li>Export în CSV</li><li>Deschidere PDF</li></ul> | <ul><li>Export în .csv</li><li>Deschidere pdf</li></ul> |

### Endpoint-uri și API-uri

Folosiți majuscule la prima cuvânt din etichete și termeni din API-uri, cu excepția cazurilor în care sunt întotdeauna scrise cu litere mici. Urmați ortografia originală în engleză, așa cum este definită în documentația VTEX.

| Corect ✅ | Incorect ❌ |
| :---- | :---- |
| <ul><li>Pentru a recupera un produs folosind ID-ul, utilizați endpoint-ul `GET /api/catalog/pvt/product/{productId}`</li><li>API Conversions.</li></ul> | <ul><li>Pentru a recupera un produs folosind ID-ul, utilizați endpoint-ul `get /api/catalog/pvt/product/{productId}`.</li><li>API de conversii.</li></ul> |

### Acronime

Folosiți majuscule pentru majoritatea acronimelor. Scrieți toate literele cu majuscule când acronimul este silabizat (de exemplu, API, HTML, CSS). Multe nume de protocoale și specificații sunt de asemenea considerate nume proprii și trebuie scrise cu inițiale majuscule (cum ar fi GraphQL și OAuth). În caz de dubiu, urmați utilizarea cea mai frecventă din industrie.

| Corect ✅ | Incorect ❌ |
| :---- | :---- |
| <ul><li>Reînnoiți tokenul API înainte de expirare.</li><li>Această opțiune implică utilizarea unei platforme externe, cunoscută sub numele de PaaS (Platform as a Service).</li><li>Cum garantează VTEX conformitatea cu Regulamentul general privind protecția datelor (GDPR)?</li><li>Mai multe redirecționări sunt posibile într-un singur URL.</li><li>O pagină de ID utilizator este afișată pentru ca clientul să continue cumpărăturile.</li></ul> | <ul><li>Reînnoiți tokenul api înainte de expirare.</li><li>Această opțiune implică utilizarea unei platforme externe, cunoscută sub numele de platform as a service (PaaS).</li><li>Cum garantează VTEX conformitatea cu regulamentul general privind protecția datelor (GDPR)?</li><li>Mai multe redirecționări sunt posibile într-un singur url.</li><li>O pagină de id utilizator este afișată pentru ca clientul să continue cumpărăturile.</li></ul> |

### Două puncte

Cuvântul de după două puncte trebuie scris cu literă mică.

| Corect ✅ | Incorect ❌ |
| :---- | :---- |
| Autocomplete: prezintă sugestii de căutare și de produse pe baza contextului consumatorului. | Autocomplete: Prezintă sugestii de căutare și de produse pe baza contextului consumatorului. |

## Interfețe de utilizator

Acțiunile și substantivele listate în etichetele de acțiune și conținut (inclusiv meniuri derulante și filtre) trebuie să înceapă cu majuscule.

| Corect ✅ | Incorect ❌ |
| :---- | :---- |
| <ul><li>Editare</li><li>Export fișier</li><li>Import fișier</li></ul> | <ul><li>editare</li><li>export fișier</li><li>import fișier</li></ul> |
| Filtrare după status: <ul><li>Confirmat</li><li>Expirat</li><li>Pregătit</li></ul> | Filtrare după status: <ul><li>confirmat</li><li>expirat</li><li>pregătit</li></ul> |

## Documentație

### Elemente ale interfeței de utilizator

În documentație, urmați capitalizarea așa cum apare în interfața VTEX. Excepție: dacă un buton are toate literele majuscule, scrieți-l cu doar prima literă majusculă în documentație.

| Corect ✅ | Incorect ❌ |
| :---- | :---- |
| Cantitatea totală de articole din pagina **Gestionare inventar** este actualizată în timp real. Faceți clic pe `Salvare`. | Cantitatea totală de articole din pagina **Gestionare Inventar** este actualizată în timp real. Faceți clic pe SALVARE. |

Când interfața este externă VTEX, urmați capitalizarea utilizată în acea interfață.

![Exemplu Google Tag Manager](https://github.com/vtexdocs/content-portal-content/blob/main/images/en/capitalization.png?raw=true)

| Corect ✅ | Incorect ❌ |
| :---- | :---- |
| În câmpul **Google Tag Manager**, introduceți ID-ul containerului dvs. în format **GTM-XXXX**, așa cum apare în imagine. | În câmpul **Google tag manager**, introduceți ID-ul containerului dvs. în format **Gtm-xxxx**, așa cum apare în imagine. |

### Referințe tehnice și câmpuri pentru dezvoltatori

Folosiți camel case pentru placeholders și câmpuri pentru dezvoltatori. Adică, scrieți cu majusculă prima literă a fiecărui cuvânt, cu excepția primei litere a întregului compus. Dacă textul este o traducere, urmați standardul de capitalizare al sursei.

| Corect ✅ | Incorect ❌ |
| :---- | :---- |
| Numele fișierului trebuie să respecte modelul *`{numeMagazin}`-favicon.ico*. | Numele fișierului trebuie să respecte modelul *`{numemagazin}`-favicon.ico*. |

## Diacritice

Româna folosește cinci diacritice: **ă**, **â**, **î**, **ș** și **ț**. În conținutul VTEX redactat în română, folosiți întotdeauna diacriticele corecte. Omiterea lor afectează lizibilitatea și poate schimba sensul cuvintelor.

| Corect ✅ | Incorect ❌ |
| :---- | :---- |
| <ul><li>țară</li><li>factură</li><li>înregistrare</li><li>ștergere</li><li>coș</li></ul> | <ul><li>tara</li><li>factura</li><li>inregistrare</li><li>stergere</li><li>cos</li></ul> |

### Când se folosesc

Folosiți diacriticele în toate textele destinate utilizatorilor români: interfață, mesaje, documentație, anunțuri și e-mailuri.

| Corect ✅ | Incorect ❌ |
| :---- | :---- |
| <ul><li>Adăugare produs</li><li>Politică de confidențialitate</li><li>Comanda a fost procesată.</li></ul> | <ul><li>Adaugare produs</li><li>Politica de confidentialitate</li><li>Comanda a fost procesata.</li></ul> |

### Când nu se folosesc

Nu aplicați diacritice acolo unde ortografia românească nu se aplică:

| Context | Exemplu |
| :---- | :---- |
| Nume de produse și mărci VTEX | Intelligent Search, FastStore |
| Identificatori tehnici | `productId`, `GET /api/catalog/pvt/product/{productId}` |
| URL-uri, adrese de e-mail și cod | `https://help.vtex.com`, `joao.silva@email.com` |
| Tag-uri de locale | `ro-RO`, `en-US` |
| Valori introduse de utilizatori | Păstrați ortografia originală a numelui sau adresei |

### Greșeli frecvente

| Tip | Corect ✅ | Incorect ❌ |
| :---- | :---- | :---- |
| **ș** vs **s** | <ul><li>ștergere</li><li>paș</li></ul> | <ul><li>stergere</li><li>pas</li></ul> |
| **ț** vs **t** | <ul><li>funcționalitate</li><li>conținut</li></ul> | <ul><li>functionalitate</li><li>continut</li></ul> |
| **î** vs **i** | <ul><li>începe</li><li>închide</li></ul> | <ul><li>incepe</li><li>inchide</li></ul> |
| **â** vs **a** | <ul><li>română</li><li>factură</li></ul> | <ul><li>romana</li><li>factura</li></ul> |
| **ă** vs **a** | <ul><li>adăugare</li><li>setări</li></ul> | <ul><li>adaugare</li><li>setari</li></ul> |

Verbele joacă un rol fundamental în crearea de conținut clar și acționabil pentru interfețe de utilizator și documentație. Ele ghidează utilizatorii, indică acțiuni și asigură că instrucțiunile sunt directe și eficiente.

## Documentație

În titlurile de documentație, folosiți un verb la infinitiv sau un substantiv. Utilizarea gerunziului este specifică limbii engleze.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Creare tabel de prețuri promoționale</li><li>Integrare cu marketplace</li></ul> | <ul><li>Creând tabel de prețuri promoționale</li><li>Integrând marketplace-ul</li></ul> |

În subtitluri, este acceptabilă utilizarea infinitivului sau a substantivului, ca în titluri, precum și a imperativului. Imperativul trebuie folosit dacă subtitlul este o comandă pentru utilizator.

| Exemplu |
| :--- |
| <ul><li>**Creare** eveniment nou</li><li>**Câmpuri** de înregistrare</li><li>**Clonați** repository-ul creat</li></ul> |

Când există instrucțiuni pentru o anumită acțiune, acestea trebuie formulate la imperativ.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Urmați pașii de mai jos: <ol><li>În Admin VTEX, faceți clic pe modulul Storefront sau tastați Storefront în bara de căutare.</li><li>În Intelligent Search, faceți clic pe Reguli de relevanță.</li></ol> | Urmați pașii de mai jos: <ol><li>În Admin VTEX, a face clic pe modulul Storefront sau tastați Storefront în bara de căutare.</li><li>În Intelligent Search, a face clic pe Reguli de relevanță.</li></ol> |

Într-o descriere de tabel, folosiți prezentul.

## Interfețe de utilizator

Începeți propozițiile cu verbe la imperativ atunci când indicați acțiunile pe care comercianții trebuie să le efectueze.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Introduceți codul poștal | Introducere cod poștal |

În **butoane**, folosiți verbul la infinitiv.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Creare produs</li><li>Vizitare magazin</li><li>Reîncercare</li></ul> | <ul><li>Creați produs</li><li>Vizitați magazinul</li><li>Reîncercați</li></ul> |

În butoane de text clicabil, folosiți imperativul.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Aflați mai mult | A afla mai mult |

Nu folosiți verbe pentru denumirea **modulelor din Admin**.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Gestionare inventar | Gestionați inventar |

Titlurile **modalelor** trebuie să conțină un verb la infinitiv pentru a indica acțiunea necesară.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Ștergere promoție</li><li>Confirmare modificare</li></ul> | <ul><li>Ștergerea promoției</li><li>Ștergând promoția</li><li>Ștergeți promoția</li><li>Confirmarea modificării</li><li>Confirmați modificarea</li></ul> |

În documentație, când o abreviere nu este familiară publicului, scrieți-o integral la prima mențiune și plasați abrevierea între paranteze imediat după.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Sistemul de management al conținutului (CMS) este o funcționalitate destinată gestionării conținutului într-un mod practic și constant. | CMS (Content Management System, în română, Sistem de management al conținutului) este o funcționalitate destinată gestionării conținutului într-un mod practic și constant. |

Următoarele abrevieri rareori trebuie explicate:

*   API
*   Formate de fișiere (PDF, XML)
*   HTML
*   RAM
*   REST
*   MB, GB
*   URL

Evitați „i.e.” și „e.g.”. Aceste abrevieri nu sunt potrivite pentru localizare și accesibilitate. Preferați formulări clare și directe.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| În această funcție, creați un obiect de eveniment specificând tipul dorit (de exemplu, „purchase”) și apelați `sendAnalyticsEvent`. | În această funcție, creați un obiect de eveniment specificând tipul dorit (e.g., „purchase”) și apelați `sendAnalyticsEvent`. |

Abrevierea recomandată pentru **„număr”** în română este **„nr.”**, cu punct. Folosiți „nr.” atât la început de expresie, cât și în mijlocul frazei. Includeți întotdeauna punctul după abreviere pentru a menține precizia și consistența tipografică.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>nr. facturii</li><li>Comanda nr. XXX</li></ul> | <ul><li>nr facturii</li><li>Comanda nr XXX</li></ul> |

## Acronime

Folosiți litere majuscule pentru acronime.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>ID comerciant</li><li>Copiere URL în clipboard</li></ul> | <ul><li>id comerciant</li><li>Copiere url în clipboard</li></ul> |

Nu creați acronime pentru numele produselor și funcționalităților.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Delivery Promise (Beta) este ideal pentru toate tipurile de operațiuni. | DP (Beta) este ideal pentru toate tipurile de operațiuni. |

Când plasați acronime și abrevieri la plural, tratați-le ca pe cuvinte obișnuite.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Maparea URL-urilor este folosită pentru a redirecționa URL-uri specifice către alte URL-uri.</li><li>Acest tip de aplicație vă permite să creați integrări între servicii folosind API-uri REST sau să creați API-uri GraphQL pentru a utiliza date în componente React personalizate.</li></ul> | <ul><li>Maparea URL-urilor este folosită pentru a redirecționa URL specifice către alte URL.</li><li>Acest tip de aplicație vă permite să creați integrări între servicii folosind API REST sau să creați API GraphQL pentru a utiliza date în componente React personalizate.</li></ul> |

Preferați formatele de fișier scrise cu majuscule. Când specificați extensii de fișier, folosiți litere mici (exemplu: „faststore.config.js”).

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Puteți configura sinonime individual sau importând o foaie de calcul în format **CSV**.</li><li>`package.json`: fișier **JSON** care descrie dependențele, comenzile de script pentru build și detaliile versiunii.</li></ul> | <ul><li>Puteți configura sinonime individual sau importând o foaie de calcul în format **.csv**.</li><li>`package.JSON`: fișier **json** care descrie dependențele, comenzile de script pentru build și detaliile versiunii.</li></ul> |

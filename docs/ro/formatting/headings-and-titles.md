Titlurile și subtitlurile trebuie să fie descriptive, scurte și, în general, să transmită o singură acțiune principală.

Clarificați obiectivul a ceea ce este abordat în articol, de preferință folosind un singur verb.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Înregistra un produs | Înregistrarea produsului |

În titlurile care indică faptul că o funcționalitate este în beta, folosiți literă mare pentru prima literă.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Capacitate operațională (Beta) | Capacitate operațională (beta) |

Nu folosiți verbul la gerunziu în titluri, așa cum este obișnuit în engleză. În română, folosiți infinitivul ori de câte ori este posibil.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Crea un tabel de prețuri promoționale | Creând un tabel de prețuri promoționale |

Folosiți literă mare numai pentru primul cuvânt din titlu, cu excepția numelor proprii.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Cum să facturezi o comandă</li><li>Filtrează datele în Master Data</li><li>Lista de reguli de merchandising</li></ul> | <ul><li>Cum să facturezi o Comandă</li><li>Filtrează datele în master data</li><li>Lista de Reguli de merchandising</li></ul> |

Nu folosiți punct final ( . ), nici italic sau bold.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Gestionează antetele HTTP | Gestionează antetele HTTP. |

Folosiți semnul întrebării numai când documentul este o secțiune de întrebări frecvente (FAQ).

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Pot avea mai mult de un abonament în magazinul meu? | Vreau să știu dacă pot avea mai mult de un abonament în magazinul meu. |

Când folosiți o abreviere într-un titlu sau subtitlu, scrieți-o pe deplin în primul paragraf care urmează titlului sau subtitlului.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <p><b>Configurarea SEO în magazinul tău Store Framework</b></p><p>SEO (Search Engine Optimization) este una dintre cele mai importante strategii pentru ca site-ul tău să obțină poziții bune în rezultatele organice ale motoarelor de căutare.</p> | <p><b>Configurarea SEO în magazinul tău Store Framework</b></p><p>SEO este una dintre cele mai importante strategii pentru ca site-ul tău să obțină poziții bune în rezultatele organice ale motoarelor de căutare.</p> |

Dacă titlul include două puncte ( : ), primul cuvânt care urmează trebuie să înceapă cu literă mică.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| VTEX Intelligent Search: editor visual nou de reguli de merchandising | VTEX Intelligent Search: Editor visual nou de reguli de merchandising |

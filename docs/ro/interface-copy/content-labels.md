Etichetele de conținut folosesc până la trei cuvinte pentru a identifica proprietăți și valori de date. Acest model este folosit frecvent în componente precum câmpuri de text sau tabele.

Păstrați textul cât mai scurt posibil, dar suficient de descriptiv.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Plată în așteptare | Așteptare plată |

Folosiți etichete în mod consistent pentru aceeași proprietate. Etichetele existente pot fi găsite în glosar.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Nume</li><li>ID</li><li>Etichete</li></ul> | <ul><li>Titlu</li><li>Identificare</li><li>Taguri</li></ul> |

Nu folosiți cuvinte deja menționate în context pentru a evita redundanța.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Titlu pagină: Promoții</li><li>Etichetă: Nume</li></ul> | <ul><li>Titlu pagină: Promoție</li><li>Etichetă: Nume promoție</li></ul> |
| <ul><li>Titlu pagină: Produse</li><li>Etichetă: Status</li></ul> | <ul><li>Titlu pagină: Produse</li><li>Etichetă: Status produs</li></ul> |

Folosiți majuscule doar la prima literă a propoziției și la nume proprii.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Data publicării</li><li>Email</li><li>Seller VTEX</li></ul> | <ul><li>Data publicării</li><li>EMAIL</li><li>Seller Vtex</li></ul> |

Nu folosiți verbe.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Nume</li><li>Status</li></ul> | <ul><li>Introduceți numele</li><li>Selectare status</li></ul> |

Nu folosiți pronume personale.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Cont VTEX</li><li>Email personal</li></ul> | <ul><li>Contul meu VTEX</li><li>Emailul meu</li></ul> |

Nu includeți cuvinte negative.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Mai mult de 6 luni | Nu în ultimele 6 luni |

Nu folosiți semne de punctuație, separatori, puncte, virgule sau semne de întrebare.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Activ | Status: activ. |

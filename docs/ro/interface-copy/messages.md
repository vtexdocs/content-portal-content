Mesajele folosesc până la două propoziții pentru a comunica starea actuală a sistemului și a oferi feedback despre acțiunile utilizatorului. Sunt folosite în componente precum câmpuri de text sau notificări.

## Reguli generale

Păstrați textul cât mai scurt posibil, dar suficient de descriptiv. Rețineți că există o limită de 240 de caractere per mesaj.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Nu s-a putut salva furnizorul din cauza unei probleme tehnice</li><li>Bifați această opțiune</li><li>Selectați cel puțin o opțiune</li><li>Nu s-au putut importa produsele deoarece fișierul CSV este invalid</li></ul> | <ul><li>Am întâmpinat o problemă neașteptată la salvarea furnizorului. Pot exista mai multe motive, precum indisponibilitatea serverului sau erori de rețea.</li><li>Bifați următoarea</li><li>Selectați cel puțin una dintre următoarele opțiuni</li></ul> |

Evitați un limbaj prea tehnic.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Nu s-a putut trimite factura din cauza unei probleme tehnice | Eroarea 298dx9283 a împiedicat trimiterea facturii |

Folosiți mesajele (sau structura folosită în acestea) în mod consistent. Mesajele cele mai frecvente sunt listate în glosar.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Colecție exportată cu succes</li><li>Nu s-a putut salva furnizorul din cauza unei probleme tehnice</li><li>Câmp obligatoriu</li><li>Bifați această opțiune</li><li>Selectați cel puțin o opțiune</li></ul> | <ul><li>Colecția a fost exportată cu succes.</li><li>O problemă tehnică a împiedicat salvarea furnizorului</li><li>Acest câmp este obligatoriu</li><li>Această opțiune trebuie bifată</li><li>Cel puțin o opțiune trebuie selectată</li></ul> |

Nu folosiți pronume personale.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Cont creat cu succes</li><li>Verificați parola introdusă</li></ul> | <ul><li>Contul dvs. a fost creat cu succes</li><li>Ați introdus parola greșită.</li></ul> |

Tonul mesajelor trebuie să fie obiectiv și neutru.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Nu s-a putut trimite factura din cauza unei probleme tehnice</li><li>Cont creat cu succes</li><li>Autentificați-vă în Admin</li><li>Verificați din nou parola</li><li>Introduceți datele</li></ul> | <ul><li>Ups, ceva nu a funcționat și factura nu a putut fi trimisă</li><li>Cont creat cu succes!</li><li>Bună ziua. Autentificați-vă în Admin</li><li>Din păcate, parola este incorectă</li><li>Vă rugăm să introduceți datele</li></ul> |

Folosiți semne de punctuație doar atunci când sunt necesare pentru înțelegere și în propoziții mai lungi.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Magazinul este editat live. Modificările vor avea efect imediat.</li><li>Nu s-a putut procesa fișierul deoarece depășește 10 MB</li><li>Colecție ștearsă cu succes</li><li>Verificați din nou parola</li><li>Încărcați o imagine de până la 5 MB</li></ul> | <ul><li>Magazinul este editat live și modificările vor avea efect imediat.</li><li>Ne pare rău, fișierul este prea mare. Pentru a evita erorile, încercați fișiere mai mici de 10 MB.</li><li>Colecție ștearsă cu succes!</li><li>Parola este incorectă, încercați din nou.</li><li>Acest fișier este prea mare. Încărcați o imagine de până la 5MB.</li></ul> |

Folosiți majuscule doar la prima literă a propoziției și la nume proprii.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Colecție exportată cu succes</li><li>Notificare indexator Intelligent Search</li></ul> | <ul><li>Colecție Exportată Cu Succes</li><li>Notificare indexator intelligent search</li></ul> |

## Reguli specifice

Pentru textele de eroare dintr-un câmp de formular, începeți cu un verb la imperativ.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Completați acest câmp</li><li>Bifați această opțiune</li><li>Selectați cel puțin o opțiune</li></ul> | <ul><li>Acest câmp este obligatoriu</li><li>Această opțiune trebuie bifată</li><li>Cel puțin o opțiune trebuie selectată</li></ul> |

În modalele de confirmare a acțiunilor, este posibil să folosiți pronume personale și semne de întrebare.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Această acțiune nu poate fi anulată. Sigur doriți să ștergeți acest produs? | Doriți să ștergeți acest produs? Această acțiune nu poate fi anulată. |

Pentru a menține consistența, fiți concis și folosiți „cu succes” la sfârșitul propoziției.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Comandă plasată cu succes</li><li>Colecție exportată cu succes</li></ul> | <ul><li>Comanda dvs. a fost plasată cu succes</li><li>Colecția a fost exportată</li></ul> |

Descrierile constau dintr-o singură propoziție menită să clarifice sau să explice informații sau sarcini complexe pentru utilizator. Acest model se regăsește frecvent în câmpurile de formulare și componentele de ajutor.

## Reguli generale

Includeți o descriere doar atunci când este cu adevărat necesar să furnizați informații suplimentare.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Etichetă: Categorie</li><li>Etichetă: Telefon</li></ul> | <ul><li><p>Etichetă: Categorie</p><p>Descriere: Introduceți categoria</p></li><li><p>Etichetă: Telefon</p><p>Descriere: Exemplu: +40 721 234 567</p></li></ul> |

Fiți cât mai succint posibil, fără a renunța la claritate.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Volum de sesiuni în etapele intermediare ale fluxului de cumpărare | Acest grafic permite monitorizarea volumului de sesiuni în etapele intermediare ale fluxului de cumpărare și vizualizarea oportunităților de optimizare a ratei de conversie |

Folosiți majuscule doar la începutul propoziției și la nume proprii.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Cronogramă actualizări</li><li>Identificator seller în marketplace</li><li>Analiză performanță a tuturor transportatorilor din VTEX Shipping Network</li></ul> | <ul><li>Cronogramă Actualizări</li><li>Identificator Seller în Marketplace</li><li>Analiză performanță a tuturor transportatorilor din VTEX shipping network</li></ul> |

Evitați utilizarea excesivă a virgulelor și nu folosiți puncte finale sau de întrebare.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Ziua în care modificările efectuate vor fi publicate, conform fusului orar al magazinului | Ziua în care modificările, efectuate anterior, vor fi publicate, conform fusului orar al magazinului. |

Folosiți o singură propoziție directă, fără punct final.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Alegeți un fișier CSV sau XLS | <ul><li>Format de fișier neacceptat. Alegeți un fișier CSV sau XLS.</li><li>Alegeți un fișier CSV sau XLS.</li></ul> |

Nu folosiți cuvinte inutile pentru a evita redundanța.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li><p>Etichetă: Frecvență</p><p>Descriere: Cronogramă actualizări</p></li></ul> | <ul><li><p>Etichetă: Frecvență</p><p>Descriere: Frecvență actualizări</p></li></ul> |

Păstrați un limbaj neutru. Nu folosiți ton de marketing și nu explicați posibile avantaje.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Volum de sesiuni în etapele intermediare ale fluxului de cumpărare | Monitorizați volumul de sesiuni în etapele intermediare ale fluxului de cumpărare pentru a optimiza rata de conversie |

## Reguli specifice

Când explicați o etichetă, scrieți ca și cum ați completa propoziția „Acesta/Aceasta este...”. Începeți cu un substantiv urmat de informații suplimentare, precum condiții și definiții.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li><p>Etichetă: ID seller</p><p>Descriere: Identificator seller în marketplace</p></li><li><p>Etichetă: Frecvență</p><p>Descriere: Cronogramă actualizări</p></li><li><p>Etichetă: Politică de confidențialitate</p><p>Descriere: Declarație a părților care gestionează datele clienților</p></li><li><p>Etichetă: Data publicării</p><p>Descriere: Data la care modificările efectuate vor fi reflectate în magazin</p></li></ul> | <ul><li><p>Etichetă: ID seller</p><p>Descriere: Acesta este identificatorul sellerului în marketplace</p></li><li><p>Etichetă: Frecvență</p><p>Descriere: Frecvența este cronograma actualizărilor</p></li><li><p>Etichetă: Politică de confidențialitate</p><p>Descriere: Completați declarația despre părțile care gestionează datele clienților</p></li><li><p>Etichetă: Data publicării</p><p>Descriere: Când trebuie reflectate modificările în magazin?</p></li></ul> |

Când explicați modul în care informațiile introduse într-un câmp de formular vor fi utilizate, scrieți ca și cum ați completa propoziția „Când introduceți o valoare în acest câmp, aceasta...” și începeți cu un verb la prezent.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li><p>Etichetă: ID seller</p><p>Descriere: Este afișat clienților în magazin</p></li><li><p>Etichetă: Frecvență</p><p>Descriere: Definește momentul publicării actualizărilor</p></li><li><p>Etichetă: Politică de confidențialitate</p><p>Descriere: Este afișată clienților în magazin</p></li><li><p>Etichetă: Data publicării</p><p>Descriere: Ține cont de fusul orar în care este localizat magazinul</p></li></ul> | <ul><li><p>Etichetă: ID seller</p><p>Descriere: Când introduceți o valoare în acest câmp, aceasta este afișată clienților în magazin</p></li><li><p>Etichetă: Frecvență</p><p>Descriere: Frecvența definește momentul publicării actualizărilor</p></li><li><p>Etichetă: Politică de confidențialitate</p><p>Descriere: Aceasta este afișată clienților în magazin</p></li><li><p>Etichetă: Data publicării</p><p>Descriere: Țineți cont de fusul orar în care este localizat magazinul</p></li></ul> |

Când explicați atât eticheta unui câmp de formular, cât și modul în care valoarea sa va fi utilizată, combinați cele două propoziții descrise la punctele anterioare și adaptați-le, dacă este necesar.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li><p>Etichetă: ID seller</p><p>Descriere: Identificator seller în marketplace afișat clienților în magazin</p></li><li><p>Etichetă: Frecvență</p><p>Descriere: Cronogramă actualizări care definește momentul publicării acestora</p></li><li><p>Etichetă: Politică de confidențialitate</p><p>Descriere: Declarație despre părțile care gestionează datele clienților care va fi afișată în magazin</p></li><li><p>Etichetă: Data publicării</p><p>Descriere: Data la care modificările efectuate vor fi publicate, ținând cont de fusul orar al magazinului</p></li></ul> | <ul><li><p>Etichetă: ID seller</p><p>Descriere: Completați identificatorul sellerului în marketplace care va fi afișat clienților în magazin</p></li><li><p>Etichetă: Frecvență</p><p>Descriere: Frecvența este programarea actualizărilor care definește momentul publicării acestora</p></li><li><p>Etichetă: Politică de confidențialitate</p><p>Descriere: Aceasta este o declarație despre părțile care gestionează datele care va fi afișată clienților în magazin</p></li><li><p>Etichetă: Data publicării</p><p>Descriere: Când trebuie publicate modificările efectuate, ținând cont de fusul orar în care este localizat magazinul?</p></li></ul> |

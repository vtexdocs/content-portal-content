Titlurile sunt compuse, de regulă, din până la trei cuvinte pentru a indica conținutul unei pagini sau al unei secțiuni specifice din aceasta. Acest model este folosit frecvent în componente precum modale sau ghiduri.

## Reguli generale

Folosiți majuscule la prima literă a primei cuvinte care începe propoziția, precum și la nume proprii.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Trimitere feedback</li><li>Help Center</li></ul> | <ul><li>Trimitere Feedback</li><li>Help center</li></ul> |

Nu folosiți semne de punctuație, precum semnul de întrebare sau punctul final.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Pagină negăsită</li><li>Ștergere utilizator</li></ul> | <ul><li>Pagină negăsită.</li><li>Ștergere utilizator?</li></ul> |

Evitați articolele.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Adăugare seller nou | Adăugare un seller nou |

Nu folosiți pronume personale.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Chei de aplicație | Cheile mele de aplicație |

Nu folosiți gerunziu în titluri.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Creare colecție | Creare colecție în curs |

Păstrați titlurile cât mai scurte posibil, fără a renunța la claritate.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Inventar</li><li>Campanii</li></ul> | <ul><li>Gestionare inventar</li><li>Campanii promoționale magazin</li></ul> |

Evitați redundanțele, omitând contextul deja prezentat. Titlul unei pagini trebuie să fie același atât în meniu, cât și la deschiderea paginii.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li><p>Titlu pagină în meniu:</p><p>Produse</p></li><li><p>Titluri pe pagină:</p><p>Produse</p><p>Categorii</p></li></ul> | <ul><li><p>Titlu pagină în meniu:</p><p>Permisiuni</p></li><li><p>Titluri pe pagină:</p><p>Permisiuni produs</p><p>Permisiuni categorie</p></li></ul> |

Nu folosiți un ton de marketing.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Căutare</li><li>Nou produs</li></ul> | <ul><li>VTEX Intelligent Search</li><li>Creați un produs cu ușurință</li></ul> |

## Reguli specifice

### Pagini

Reutilizați același titlu de pagină ori de câte ori este posibil, precum în URL, în meta tag-ul de titlu și, când este cazul, într-un element de navigare.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Titlu pagină: Comenzi</li><li>Meta tag titlu: Comenzi</li><li>URL: /comenzi</li><li>Element navigare: Comenzi</li></ul> | <ul><li>Titlu pagină: Comenzi</li><li>Meta tag titlu: Listă comenzi</li><li>URL: /toate-comenzile</li><li>Element navigare: Comenzi magazin</li></ul> |

Într-un formular, la editarea unui element, folosiți numele acestuia ca titlu de pagină. La crearea unui element nou, folosiți cuvântul „Nou” urmat de tipul elementului.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Reducere de Crăciun</li><li>Nou produs</li></ul> | <ul><li>Produs</li><li>Produs fără nume</li></ul> |

Pe o pagină de listare, folosiți tipul elementelor listate ca titlu de pagină. Includeți doar substantive la plural și evitați prefixe sau sufixe inutile.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Produse</li><li>Comenzi</li></ul> | <ul><li>Toate produsele</li><li>Listă produse</li></ul> |

### Modal

Într-un modal de formular sau acțiuni, folosiți o [etichetă de acțiune](https://contentguide.vtex.com/ro/docs/interface-copy/action-labels) ca titlu. Dacă modalul a fost declanșat de o acțiune, repetați verbul acțiunii care a deschis modalul.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Ștergere politică de livrare</li><li>Creare lansare</li></ul> | <ul><li>Politică de livrare</li><li>Creare</li></ul> |

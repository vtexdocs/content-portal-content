Textele placeholder folosesc o singură propoziție pentru a ghida utilizatorul despre modul de interacțiune cu un câmp de formular înainte de a introduce orice valoare. Acest model este frecvent în componente precum câmpuri de căutare și selecție.

## Reguli generale

Evitați personalizarea textelor placeholder. Utilizatorul trebuie să știe intuitiv ce informații să introducă.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li>Căutare</li><li>Selectați…</li></ul> | <ul><li>Căutare după nume</li><li>Selectați o opțiune...</li></ul> |

Evitați redundanțele.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| <ul><li><p>Titlu pagină: Produse</p><p>Placeholder: Căutare după categorie sau ID</p></li><li><p>Etichetă: Categorie</p><p>Placeholder: Selectați…</p></li></ul> | <ul><li><p>Titlu pagină: Produse</p><p>Placeholder: Căutare după categorie de produs sau ID produs</p></li><li><p>Etichetă: Categorie</p><p>Placeholder: Selectați categoria…</p></li></ul> |

Folosiți maximum 36 de caractere.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Căutare după nume sau ID | Căutare după nume, ID, ID referință sau descriere |

## Reguli specifice

Când scrieți textul placeholder al câmpului Selectați, includeți puncte de suspensie la sfârșit.

| Corect ✅ | Incorect ❌ |
| :--- | :--- |
| Selectați… | Selectați |
